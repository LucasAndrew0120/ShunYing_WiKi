# vitepress-wiki-kit

为 VitePress 1.x 提供自动导航、中文搜索、XLSX 渲染、Markdown 增强和可复用内容组件。

## 入口

- `vitepress-wiki-kit`：Gallery、AppCards、Flink/Flinks、ImageViewer 和组件安装器
- `vitepress-wiki-kit/markdown`：字数、阅读时间、图片题注、友链容器和可选 XLSX 渲染
- `vitepress-wiki-kit/xlsx`：XLSX 插件和腾讯文档缓存键工具
- `vitepress-wiki-kit/config`：内容树、开发监听器、站点统计和中文搜索 tokenizer
- `vitepress-wiki-kit/twikoo`：可选 Twikoo 评论组件
