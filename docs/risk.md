# 瞬影 Emby 风控机制及播放器使用公告

::: warning 重要公告
鉴于近期盗链行为及普通用户提权等安全风险，为保障服务器稳定运行和正常用户的观影体验，瞬影已内置**异常请求拦截**与**账号风控机制**。请各位用户仔细阅读以下说明。
:::

## 一、异常请求拦截机制

瞬影会对客户端发起的请求进行监测。超出正常播放需求、存在明显异常特征的请求，将被判定为可疑或恶意请求，并触发风控机制。

触发风控后，用户可能遇到 **403 Forbidden**，表现为无法播放、播放中断或请求被拒绝。

::: danger 特别提醒
部分新款播放器存在**请求频率异常**的问题。播放单个视频时，可能产生**上万次请求**，即使用户本人没有恶意操作，也可能触发系统风控，导致 403。
:::

## 二、白名单播放器机制

为减少误触发风控的情况，建议大家优先使用经过验证、用户基数较大且请求行为正常的播放器。

也可在本站 [播放器白名单](/player/) 查看。请优先参考上述名单选择播放器，避免因客户端请求异常影响正常观影。

## 三、账号共享风控规则

为防止账号共享、多人异地使用等异常行为，瞬影设有 **IP 地理位置风控机制**：

- **跨市风控**：在一定时间内，IP 所属城市范围跨越达到或超过 **3 个城市**，将触发风控判定。
- **跨省市封禁**：在一定时间内，IP 涉及跨省市范围达到或超过 **3 个**，将**直接封禁账号**。

::: tip 请注意
以上规则以系统在规定时间内统计的 IP 地理位置范围为准。使用 **VPN、代理或网络线路切换** 时，也可能出现 IP 归属地变化，请谨慎操作。
:::

## 四、温馨提示

- 请使用推荐的白名单播放器，尽量避免使用请求行为异常的客户端。
- 请勿共享账号、转借账号或进行其他可能触发风控的操作。
- 如果确认自己属于正常使用，却遇到 403 或账号被封禁，请联系管理员核查。

瞬影将持续打击盗链及异常访问行为，优先保障正常用户的稳定播放体验。感谢大家的理解与配合！
