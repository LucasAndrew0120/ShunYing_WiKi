# 常见问题

**Q：我不知道安全码怎么办？**

A：按上面的规则计算。**老用户 = Emby 密码 + syemby**，**新用户 = 用户名 + syemby99**。

**Q：我连 Emby 密码也忘了怎么办？**

A：下个号见。

**Q：我显示“未注册”怎么办？**

A：迁移后所有用户状态已修正为正常，如果仍有问题请联系管理员。

**Q：签到、花币、到期时间还在吗？**

A：全部保留，数据完整迁移。

**Q：修改 Emby 密码后，安全码会变吗？**

A：不会，安全码请自行保存。
