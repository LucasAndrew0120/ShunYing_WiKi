# Emby 播放器白名单

::: warning 白名单播放器模式已正式启用
瞬影已启用**白名单播放器模式**，**仅允许白名单内的播放器访问，非白名单 UA 一律禁止访问**。
:::

## 总体规则

1. 仅允许使用下方白名单内的播放器
2. 禁止网页端登录
3. 禁止 Emby 官方客户端
4. 禁止一切媒体库模式
5. 禁止使用来历不明的播放器

## ⚠️ 账号与线路安全提示

- 使用来历不明的播放器（例如在闲鱼购买的共享播放器），可能导致**服务器线路以及你的账号密码泄露**。
- 如果账号后台出现**多地异地 IP 登录**，账号将**直接封禁**。
- 修改密码后需**扣除 15 天**方可解封；**如剩余时间不足 15 天则不予解封**。
