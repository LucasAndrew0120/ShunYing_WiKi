# 瞬影使用说明

## 概览
瞬影分为 VIP 服和 PRO 服，均提供移动优化的线路，电信和联通用户可以使用主线路。**禁止泄露线路**，**更不要在国内社交平台宣传**

## 求片
瞬影的定位是，**极速播放和高码追新**，欢迎大家求片，求片尽量携带**TMDB链接**



## 封禁底线（击落）
1. **登录禁用的设备**
2. **换绑账号**
3. **退出群组**
**触碰以上规则的都会秒封，不支持解封**

## 同播数量限制
- VIP 服同播数限制为 3，PRO 服同播数限制为 2（后台将不定时进行抽查）。
- **防误封建议**：在关闭播放后，请务必等待几十秒，让服务器彻底释放连接后，再更换设备或播放器进行播放，以免被系统判定为多播。

## 安全码说明

::: tip
安全码用于 注销账号、重置密码、换绑TG 等敏感操作。
:::

- **正常用户：** `安全码 = 你的 Emby 登录密码 + syemby`,例：`密码是 abc123 → 安全码是 abc123syemby`。
- **密码错误的用户（原有的emby账号密码无法登录emby）:** `安全码 = 你的 Emby 用户名 + syemby99`,例：`用户名是 zhangsan → 安全码是 zhangsansyemby99`

## 修改密码步骤
1. 私聊 [@syembyy_bot](https://t.me/syembyy_bot)
2. 发送 /start 打开面板
3. 点击 「重置密码」
4. 输入安全码验证（格式见上方）
5. 输入新密码
6. 修改成功 ✅

## 常见问题

Q：我不知道安全码怎么办？

A：按上面的规则计算。老用户 = Emby密码+syemby，新用户 = 用户名+syemby99。

Q：我连 Emby 密码也忘了怎么办？

A：下个号见。

Q：我显示"未注册"怎么办？

A：迁移后所有用户状态已修正为正常，如果仍有问题请联系管理员。

Q：签到、花币、到期时间还在吗？

A：全部保留，数据完整迁移。

Q：修改emby密码后，安全码会变吗？

A：不会，安全码请自行保存
